# 🌟 Personal Portfolio – Full-Stack Developer

Welcome to my full-stack personal portfolio website! This project was built to showcase who I am as a developer — from my background and experience to the technologies I work with and the projects I’ve built.

Explore my journey, view my projects, see my skills, and download my resume — all in one place.

---

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) – Server-side Rendering & API Routes
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/), [Sass](https://sass-lang.com/)
- **Database:** [PostgreSQL](https://www.postgresql.org/)
- **Deployment:** [Vercel](https://vercel.com/)

---

## ✨ Features

- 👤 **About Me** – Learn more about who I am and what drives me  
- 💼 **Work Experience** – A summary of my career journey  
- 🛠️ **Skills** – Technologies, languages, and tools I work with  
- 🚀 **Projects** – A showcase of my development work with descriptions  
- 🏆 **Achievements** – Courses, certifications, and accomplishments  
- 📄 **Resume / CV** – Downloadable for potential employers  
- 🌈 **Responsive UI** – Optimized for all screen sizes  
- 🔒 **Secure & Fast** – Full-stack performance with secure integration
